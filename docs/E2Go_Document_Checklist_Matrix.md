---

## HOW TO READ THIS MATRIX

**Status codes:**
- ✅ REQUIRED — Must be included in every standard application of this type
- ⚡ CONDITIONAL — Required only if a specific condition applies (noted in the Condition column)
- 🔁 RENEWAL ONLY — Required only at renewal, not for initial application
- ❌ DO NOT INCLUDE — Harmful or irrelevant; explicitly excluded

**Source codes:**
- GEN — E2Go generates this document from user inputs
- UPLOAD — User uploads this document into E2Go
- COLLECT — User physically obtains and holds this document (not uploaded to E2Go)
- EXTRACT — E2Go generates a reference/checklist; user collects the actual item

## TAB A — COVER LETTER

| # | Document | Status | Case Types | Condition | Source | Notes |
|---|---|---|---|---|---|---|
| A.1 | Cover letter addressing all 6 E-2 eligibility elements | ✅ REQUIRED | All | None | GEN | Generated by Document Builder from interview answers |
| A.2 | Reference to date of initial visa issuance | ⚡ CONDITIONAL | All | Only if company previously held E visa status | GEN | Auto-populated from user input if renewal or prior E visa noted |
| A.3 | Role differentiation statement (Investor 1 vs. Investor 2) | ⚡ CONDITIONAL | Partnership | Two co-investors | GEN | Separate section in cover letter; describes distinct duties of each investor |
| A.4 | Adult child co-investor acknowledgment and role description | ⚡ CONDITIONAL | Adult child as co-investor | Child 21+ as partner | GEN | Each investor files separate binder; this appears in each letter |
| A.5 | Treaty employee role justification | ⚡ CONDITIONAL | Treaty employee | Adult child or other employee applying | GEN | Must cite 9 FAM 402.9-7(B) or 9 FAM 402.9-7(C) as applicable |

**The 6 mandatory elements the cover letter must address:**
1. Investor has invested or is actively in the process of investing
2. The enterprise is currently running or will open imminently
3. The investment is substantial
4. The investment is more than marginal
5. The investor is in a position to develop and direct the enterprise
6. The investor intends to depart the U.S. when E-2 status ends

## DOCUMENTS TO EXCLUDE

| # | Document | Why Excluded |
|---|---|---|
| X.1 | Unsigned / draft versions of any document | Must be fully executed; drafts carry no evidentiary value |
| X.2 | Generic business plan templates | Officers identify non-customized plans; weakens credibility |
| X.3 | Social media screenshots as proof of operation | Carry minimal evidentiary weight; not an official record |
| X.4 | Overly optimistic projections without supporting assumptions | Officers discount unrealistic numbers; may trigger additional scrutiny |
| X.5 | Personal Canadian financial documents unconnected to the investment | Irrelevant; waste of the 50-page limit |
| X.6 | Letters of intent without executed agreements | An LOI to sign a lease is not a lease |
| X.7 | Prior denial letters or refusal notices | Do not include unless specifically requested by the officer |
| X.8 | Documents contradicting other binder documents | Internal inconsistency is the most common 221g trigger |
| X.9 | Loans secured against the business itself (not personal assets) | These do not count as qualifying at-risk investment |
| X.10 | Funds sitting in a U.S. bank account without deployed investment evidence | Wire transfers alone are insufficient; actual purchases must be evidenced |

## DOCUMENT STATUS TRACKER (E2Go App Logic)

Each document in this matrix maps to one of four states in the E2Go application tracker:

| State | Meaning | App Display |
|---|---|---|
| ✅ Complete | Document generated, uploaded, or confirmed by user | Green checkmark |
| 🔄 In Progress | Document started but not finalized | Yellow progress ring |
| ⏳ Pending | Document not yet started; required for this application type | Grey clock icon |
| ⚡ Triggered | Conditional document now required based on user's specific inputs | Orange lightning bolt |

The Application Confidence Score (0–100) increases as documents move from Pending → Complete.
