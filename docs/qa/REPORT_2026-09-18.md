## 2. The critical finding (fixed in the repo, NOT deployed)

**F-000 (S0) — `/admin/users/[userId]/view` leaked another user's e-mail and admin data to any signed-in non-admin.**
Persona B could fetch persona C's data and vice-versa: the page's service-role queries ran and streamed into the response even though a layout redirect fired. Fixed with a `requireAdmin()` guard at the top of the page ([page.tsx](../../src/app/admin/users/[userId]/view/page.tsx)); re-verified on a rebuilt server (non-admin gets 404). **The change is uncommitted; production is still exposed until it is deployed.**
Lesson: a layout `redirect()` does not protect a page's own service-role queries. Every service-role page needs its own guard (worth a lint/grep check).

## 4. Other things worth your attention (not scored)
- **Performance:** homepage ships heavy PNG heroes and about 26 JS files; LCP/CLS could not be measured because the pane was hidden.
- **Dependencies:** `npm audit` shows 1 critical (`next`), 11 high (including direct `xlsx`, `postcss`, `eslint-config-next`), 2 moderate, 1 low. Lint warnings 371 vs the 359 baseline.
- **Stale docs:** UAT-01/04 entries and the tracker are behind reality; UAT-02 still open. Homepage meta says "From $550" while Foundation is $990.
- **Legal copy:** all-caps `E2GO.APP` in `TermsClient.tsx:258,261` (your decision: brand rule vs legal all-caps).
- **Email copy:** "opens once" claim is false for the results e-mail.
- **Service worker:** cache-first strategy risks stale pages; `OFFLINE_URL` is dead. `/api/quiz/submit` rate-limit config is dead.
- **Sentry tunnel** could not be verified: the scratch build had no Sentry env, so the `tunnelRoute` rewrite was absent.
- **Environment hygiene:** stray dev servers on :3000 and :3010 and a stray prod build (PIDs 57146/57161/57163, 60174/60186/60189) were left running; I was not permitted to kill them and did not work around that. A hung `vercel env add` (PID 64126) exposes a Stripe test key in its command line — kill it and rotate the key.
- **Shared infrastructure:** local `.env.local` and production use the same Supabase project and Upstash. QA reads and 429s landed there. A staging project is strongly advised before the next run.
- **Not touched:** persona A (your real account) was never logged into.
